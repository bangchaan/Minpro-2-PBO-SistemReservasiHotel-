# *SISTEM RESERVASI HOTEL*


## DESKRIPSI PROGRAM
Sistem Reservasi Hotel merupakan program sederhana berbasis Java yang digunakan untuk mengelola data kamar dan reservasi hotel. Program ini memungkinkan pengguna untuk menambahkan data kamar, melihat data kamar, melakukan reservasi kamar yang tersedia, melihat data reservasi, memperbarui jumlah malam menginap, serta menghapus reservasi.

## ALUR PROGRAM

### MENU UTAMA
<img width="320" height="172" alt="image" src="https://github.com/user-attachments/assets/74b13cb3-f3f0-4a68-bb75-f799ceac164a" />

Gambar di atas merupakan menu awal, yang meminta pengguna untuk memilih opsi menu yang tersedia.
Terdapat 3 opsi pada menu utama, yaitu:

1. Kelola Kamar: untuk menambahkan dan melihat data kamar.
2. Menu Reservasi: untuk menambah, melihat, memperbarui, dan menghapus data reservasi.
3. Keluar: untuk menghentikan program.

Setelah mengetahui opsi yang diinginkan, pengguna dapat menginputkan opsi yang diinginkan (1-3).

### MENU KELOLA KAMAR

<img width="237" height="107" alt="image" src="https://github.com/user-attachments/assets/264a67d4-af54-44e6-934a-ac623ae642a0" />

Gambar di atas merupakan menu Kelola Kamar, yang digunakan untuk mengelola data kamar. Terdapat 3 opsi, yaitu:

1. Tambah Kamar: untuk menambahkan data kamar baru.
2. Tampilkan Semua Kamar: untuk menampilkan seluruh data kamar yang tersimpan.
3. Kembali ke Menu Utama: untuk kembali ke menu awal.

Pengguna dapat memilih opsi dengan menginputkan angka 1–3.

### MENU RESERVASI
<img width="280" height="156" alt="image" src="https://github.com/user-attachments/assets/97fc648b-4fd2-469a-9839-bdd1e1c252d8" />

Gambar di atas merupakan menu reservasi, yang meminta pengguna untuk memilih opsi menu yang tersedia.
Terdapat 5 opsi yang tersedia, yaitu:

1. Tambah Reservasi: untuk membuat reservasi baru.
2. Tampilkan Semua Reservasi: untuk menampilkan semua data reservasi yang tersimpan.
3. Update Data Reservasi: untuk mengubah data reservasi yang tersedia.
4. Hapus Reservasi: untuk menghapus data reservasi yang tersedia.
5. Kembali ke Menu Utama: untuk kembali ke menu awal.

Setelah mengetahui opsi yang diinginkan, pengguna dapat menginputkan opsi yang diinginkan (1-5).
